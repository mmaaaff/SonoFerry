# Third-party sources

SonoFerry (formerly MacLDAC) is a local experimental macOS audio application. Original SonoFerry additions are MIT-licensed. Modified upstream files retain their original notices.

- **Acouplet** — https://github.com/baglayan/Acouplet, commit `1ade5778adfeb9b6702cec6b870207c3e8da5def`, MIT. Selected native HAL, Classic L2CAP transport, Core Audio capture, route and session lifecycle code was adapted. License: `Vendor/Acouplet-LICENSE`. The Sony control prerequisite, branding and signing identity were removed. SonoFerry uses its own engine CDHash requirement and bundle identifiers. The generic headphones icon is from the same source.
- **AOSP libldac** — https://android.googlesource.com/platform/external/libldac/, commit `eeee1a3f5f8df1282e3a6d297085885fd886737b`, Apache-2.0. Source and license preserved in `Vendor/libldac`.
- **LHDC V5 Encoder** — https://github.com/WillyBilly06/LHDC-V5-Encoder, commit `3f9d1980fa9c57cdfb78792f9455a7dbac50edda`, Apache-2.0. Source and license preserved in `Vendor/lhdcv5`. Its FFT includes KISS FFT BSD-3-Clause notices. This is the pinned community C99 encoder; SonoFerry does not claim it is an official macOS codec implementation.
- **Apple NullAudio** — Apple sample-code license, preserved in `Native/Driver/LICENSE.txt` and the source header of `Native/Driver/NullAudio.c`.

Protocol reference: Android `android17-release` Bluetooth `system/stack/a2dp/a2dp_vendor_lhdcv5.cc`, `a2dp_vendor_lhdcv5_encoder.cc` and `system/stack/include/a2dp_vendor_lhdcv5_constants.h`. LHDC media headers use `(frame_count << 2)` and an 8-bit packet sequence; RTP timestamps count actual PCM samples. LDAC capabilities have no remote PCM bit-depth field.

OPPO control protocol reference (no implementation copied): https://github.com/GreenTeodoro839/OPPOEarPhoneForHyperOS, `Packets.kt` and `.research/PROTOCOL_FINDINGS.md`, consulted 2026-10-11. Those Enco X3 protocol observations are not treated as verified Enco X4 compatibility. The SonoFerry control adapter, transactions and bounded stream parser are independently implemented. X4 compatibility was subsequently verified using the user’s phone component and hardware; see `docs/OPPO-CONTROL.md`. Extracted APKs/libraries are local analysis inputs and are not distributed. The vendor-derived UI artwork exceptions are the DYNAUDIO preset badge, real-time noise badge and four noise mode icons described below.

Optional independent verification downloads WillyBilly06/LHDC-V5-Decoder commit `676af03d2b7a2ed5c1f9bdca7bf8938cc85f704b` to ignored `work/reference-decoder`. It is used only for local interoperability tests and is not included in the application or install packages.

Optional LDAC verification downloads hegdi/libldacdec commit `7f3bd6cc1586b764b02f2e4f20b16c7ff18758b9` (MIT) to ignored `work/reference-ldac-decoder`, with its license and SHA-256 manifest preserved. It is only a local independent decoder test dependency and is not included in application or install packages. The optional decoders are exercised with locally generated test signals, not untrusted media.

The **CO-CREATED WITH DYNAUDIO** badge shown beside Enco X4 presets uses the original path geometry from the user-provided Melody 17.6.3 APK resource `melody_ui_equalizer_dynaudio` (0x7f08058b), transcribed to SwiftUI in `Sources/App/DynaudioBadge.swift`. This vendor artwork and its trademarks remain the property of their respective owners; they are not covered by SonoFerry's MIT license. It identifies the headphone's existing presets and does not imply an endorsement of SonoFerry. Original resource XML and local evidence are not included in this public repository. See `docs/OPPO-CONTROL.md` for the public provenance summary.

The **实时计算** badge beside Enco X4 deep noise cancellation uses the original white path geometry and blue background from Melody 17.6.3 `drawable-zh-rCN/melody_ui_reduction_noise_strong_realtime.xml`, transcribed to SwiftUI in `Sources/App/RealtimeNoiseBadge.swift`. This vendor artwork remains its owner’s property and is not covered by SonoFerry’s MIT license. Original resource XML and local evidence are not included in this public repository.

The four Enco noise mode icons use the original 24×24 path geometry from Melody 17.6.3 resources `melody_ui_reduction_noise_strong`, `melody_ui_reduction_noise_adaptive`, `melody_ui_reduction_noise_transparent`, and `melody_ui_reduction_noise_close`, transcribed to SwiftUI in `Sources/App/NoiseModeIcon.swift`. This vendor artwork remains its owner’s property and is not covered by SonoFerry’s MIT license. Original XML files, hashes and device evidence are retained only in the local research archive and are not part of this public repository.
